# I-80 WB / Ramp G - agent review of curbs

Agent review (2026-10-30) of every curb the I-80 WB set (Iowa DOT Design 116, `dist\SteelBridgeModeler\B00168 ... Design 116.pdf`, 240 pages) and the Ramp G set
(Design 316, `B00169 ... Design 316.pdf`, 174 pages) show, compared with `samples/plans/I-80 WB and Ramp G.sbm`. Both PDFs have a text layer on every page. I searched
both for CURB, CUSHION, ATTENUATOR, GORE, RAISED, ISLAND, MEDIAN, SIDEWALK, END SECTION, DRAIN BLOCK, POLE BASE and SIGN SUPPORT, then rendered the sheets that matched.
I measured the model with the debug CLI (`qc/i80-rampg/curbs/work/probe.csx`, output `probe.out`). Nothing in the model, the scripts or the source was changed.

PDF page = sheet number + 1 (for example sheet 190 = PDF 197). Offsets are LT of the I-80 CL unless noted (WB CL = I-80 CL + 41.08 ft LT).

## Summary

- **Neither plan set has a curb.** The "crash cushion curb" in `cross-slope-i80.csx` is top of slab, not a raised curb:
  - Sheet 190 is titled "PLAN - TOP OF SLAB CROSS SLOPE".
  - The slab elevations run straight across the strip.
  - Sheet 222's elevation shows the cushion standing on the deck.
  - Neither set has a curb pay item or curb bars.
  
  The model's deck surface matches the plan elevations to 0.01 ft. Everywhere else in both sets, "curb" means the barrier face (expansion joint notes: "curb plates", "section at curb").
- **The curb-like concrete the plans do show is the two CRASH CUSHION END POSTS, and the model has neither as a solid.** `end-posts.csx` and the generator call their position "not dimensioned". In fact sheets 190 / 191 Detail A give every corner by station and offset. Three further problems:
  - The Ramp G post is on the wrong unit: Unit 2 instead of Unit 3.
  - The Ramp G wedge is not symmetric, so the generator's input cannot describe it.
  - The rail part of each post (between the end of slab and the start of the wedge) is not in the generator.
- **The barrier cover (slider) plates "at the curbs" are missing at every joint.** These are the plates at the barrier face at each modular joint and at the Ramp G strip seal. The pay items include them, but the model has no input for a plate on the barrier face.
- Related, outside strict curb scope: the barrier is a generic F-shape approximation. Its area matches the plan (3.46 SF), but its face geometry does not.

Count: 0 wrong curb solids; missing 4 (I02, I04, I05, I07); wrong 1 (I03); unclear 3 (I06, I08, I09); OK 3 (I01, I10, I11); minor documentation 1 (I12).
