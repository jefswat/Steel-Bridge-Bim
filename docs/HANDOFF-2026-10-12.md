## Options to evaluate
- **True solids kernel (OpenCASCADE, LGPL):** the program does not use a solid-modeling kernel today; its own code builds meshes, and with "Exact curves" on, exact NURBS B-rep-light solids for curved parts (no general cuts or booleans, faces not linked, everything downstream reads the mesh). OpenCASCADE today appears only inside IfcOpenShell in `tools/validate_ifc.py`. Evaluate (a) converting the generators' exact NURBS faces into OCC solids so copes, clips and holes become real cuts, or (b) using OCC only for booleans, exact clash volumes and STEP export. Needs a C# wrapper around the C++ libraries; add to the third-party notices if adopted. Alternatives: Parasolid / ACIS (commercial).
