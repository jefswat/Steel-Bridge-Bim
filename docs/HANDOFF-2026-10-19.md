**Merge pattern used today:**
1. Agents work in worktrees (`.claude\worktrees\agent-*`, branch `worktree-agent-<id>`); merge with `--no-ff`. Stash or restore the local CLAUDE.md sandbox note first (`temp/sandbox-line.txt` holds it).
2. When a branch rebuilt a model (`.sbm`), do NOT text-merge the file. Take main's `.sbm` and re-run that branch's script on it:
   - `sbm run samples/plans/weld-holdbacks.csx <model>` (it saves)
   - `arch-nht.csx <model> -- <model>` (it saves)
   - `rail-joints-nht.csx`, via `temp/run-rail-and-save.csx`
3. Then run the check scripts.

**Publishing:** fails while the app is open on the user's PC (dist is the same folder on the host), or while a QC checker uses `dist\sbm.exe`.
