**The file name is misleading.** The title block of every sheet reads **Iowa DOT DESIGN NO. 1617, FILE NO. 30377**, project
IM-NHS-029-6(206)147--03-97, Woodbury County (Sioux City), October 2015, letting 12-15-2015 (p.1, p.4). It is NOT
Design 116 (I-80 WB Council Bluffs = Design 116 / File 30169, Pottawattamie County) and has no geometric, structural or
georeference relation to the I-80 WB / Ramp G sets (B00168 / B00169). It belongs to the same Sioux City I-29
reconstruction (File 30377, tied roadway project IM-NHS-029-7(49)149--03-97) as `woodbury-i29-floyd` (Design 817,
project IM-NHS-029-6(201)). "B00167" is the (Iowa) bridge/file label of the PDF only.

Bridge: NEBRASKA ST. RAMP B over Virginia St. and Virginia St. Ramp D. 570'-0 x 26'-0 continuous welded plate girder
bridge, 3 spans 180'-0, 203'-0, 187'-0 (along CL Nebraska St. Ramp B), "design for variable skew", 4 weathering-steel
plate girders A-D, pier 1 = concrete 2-column pier with cap, **pier 2 = 2 columns + integral steel (twin I-girder) pier cap**
straddling Virginia St. Ramp D, stub abutments on HP12x84 piles, disc bearings (14), 1 continuous unit, strip-seal
expansion devices (steel extrusion joint) at both abutments. No revision sheet, no void / superseded sheets found.

Page numbering: PDF page p = project SHEET NUMBER p (pages 2-66); DESIGN SHEET = p - 1 (design sheets 1-65 of 65).
