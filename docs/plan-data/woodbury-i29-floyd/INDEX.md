# woodbury-i29-floyd - sheet index

Plan set: `Woodbury 0817 Sioux City I-29 NB over Floyd Blvd_Rev1.pdf` (48 PDF pages, 11x17, Iowa DOT / HDR).
Iowa DOT Design No. 817, File 30377, Project IM-NHS-029-6(201)147--03-97, letting 12-22-2015, Rev. 1 = 04-07-16
(piles changed from end bearing to friction piles; sheets RA, 2, 3, 5, 11, 16).

Bridge: 223'-10 7/8 x 36'-0 pretensioned prestressed concrete beam bridge (BTD bulb tees), STAGE 1 of the new
I-29 NB bridge over Floyd Blvd (stage 2 = Design 217, built under IM-NHS-029-6(200), not in this set). 3 spans
55'-11 15/16, 106'-11 7/16, 60'-11 1/2 (along CL NB roadway), integral abutments, 2 three-column piers (stage 1 part).

Page numbering: PDF page p = project sheet number p-1 (pages 3-44) = design sheet p-2 (design sheets 1-42 of 42).
