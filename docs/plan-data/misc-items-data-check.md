# Data sufficiency check: Ramp G drainage, sign supports, crash cushion end posts, lighting

Read from the PDF sheets (rendered and read; text layer used for tables where it is clean). PDF pages are 1-based; "design sheet" = printed
sheet number. Fractions and small dimensions were read from images and are marked UNCERTAIN where the print was too small to confirm.
Per the standing rule, nothing is filled in by assumption: gaps are listed as UNRESOLVED / MISSING.

Existing model input for drains (code): `DeckDrainDefinition` in `src/SBM.Core/Bridge/BridgeDefinition.cs` = Station, Left (side), FromGutter (inlet center
from barrier toe), Type (string), Outlet (FreeFall | PipedToPier), SplashBasin (bool), InletLength (24") x InletWidth (12"), PipeDiameter (8"), DropBelowGirders (1'-0).
`SubstructureGenerator` builds a box inlet (long side along the alignment), a downspout, an optional 10' x 10' x 2' splash basin, and for PipedToPier a drop pipe,
a collector 1'-0 below the girders to the nearest pier and a >=12" pier downspout. I-80 drains are already entered (`samples/plans/build-i80-wb.csx`, 41 drains from the
I-80 table of deck drains, PDF 221 = design sheet 214; the script comment says "design sheet 220", which is not the sheet number of the table); Ramp G has NO drains in the model.

Differences vs the existing `DeckDrainDefinition` that need inputs (nothing here is guessed, all values are printed):
1. Inlet orientation and size: Ramp G inlet = 4'-0 across the deck (2 panels) x about 10" along the roadway; the model's inlet box has its LONG side along the alignment (24" x 12" default). Needs InletLength/InletWidth values and an orientation flag (transverse). UNRESOLVED on the plan: the exact grate width (the "10 +/-" is printed with a tolerance) and the exact distance of the drain centre from the gutter line (only the 1/2" clearance and the 4'-0 length are printed).
2. Offset "LEFT / RIGHT" is the side of the deck; the model's Left/FromGutter fits. The plan also prints no distance from CL Ramp G in the table (UNRESOLVED if a numeric offset is needed, PDF 160).
3. Collector: the model's PipedToPier runs 1'-0 below the girders to the nearest pier. The plan's piped system is 12" collection pipe under the deck on hangers with couplers (pitch 1.78%, vertical distances to the deck printed per drain on PDF 159), ending in a pier collection box at Pier 19G; the other drains free fall from the deck. A new "collection pipe" element would be needed for pipe path, hangers, couplers, cleanouts.
4. Pier-level items (trough collection boxes, pier collection boxes, neoprene troughs, pipe supports) are not in the model; all have dimensions on PDF 154-159 (see above), so they are modelable, but locations are given by pier name only (Piers 5G, 9G, 14G, 19G) and by sections, not by coordinates.
Minimal inputs for the inlets: 25 x {station, side, free fall, splash basin} (all printed), inlet 4'-0 transverse x ~10", pipe 8" dia, gutter clearance 1/2" (printed). For piped drains: pipe 12", slope 1.78%, drain-to-deck vertical distances (printed on PDF 159), hanger spacing 5'-0 max.
